Privacy Policy

What this is

This is a personal job application tracker. It is used only by its developer.

Google data it reads

The app reads Gmail messages in the signed-in account to find replies to job applications. Access is read only. It does not send, delete or change any mail.

Where data is kept

Data is kept on a private backend run by the developer.

How data is used

Data is used only to show application status to the account owner. Email text is sent to Anthropic's Claude API to work out the status of each application. It is not shared with anyone else, not sold and not used for ads.

Google API limited use

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can remove the app's access at any time at https://myaccount.google.com/permissions. Stored data is deleted on request.
